ClipVault 0.2.0 — тестовая сборка Windows x64

УСТАНОВКА
1. Запустите ClipVault-0.2.0-x64-setup.exe.
2. Выберите папку и при необходимости ярлык на рабочем столе.
3. Если Microsoft WebView2 отсутствует, установщик скачает его компоненты.
   Для этого нужен интернет. Rust и Node.js не требуются.
4. Запустите ClipVault из меню «Пуск».

Есть также отдельный ClipVault-0.2.0-x64.exe. Для его запуска WebView2
должен быть уже установлен.

ИСПОЛЬЗОВАНИЕ
Копируйте текст или изображение — приложение сохраняет локальную историю.
Поиск, закрепление, избранное, теги и коллекции находятся в главном окне.
Ctrl+Shift+V открывает быстрый доступ; стрелки выбирают запись, Enter
возвращает её в буфер. Затем вставьте вручную с помощью Ctrl+V.
Шаблоны создаются в Snippets. Пауза находится внизу боковой панели.
В Settings доступны тема, язык, инкогнито, лимиты и автозапуск.
Автозапуск включается только вашим действием.

При включённом close-to-tray закрытие окна оставляет программу в трее.
Для полного выхода выберите Quit в меню значка трея.

ПРИВАТНОСТЬ
История не зашифрована и может содержать пароли. Приостановите запись
или включите инкогнито перед копированием конфиденциальных сведений.
Распознавание некоторых токенов и исключения приложений не дают полной
защиты: неизвестного владельца буфера приложение может не распознать.

ОГРАНИЧЕНИЯ ЭТОЙ СБОРКИ
EXE и установщик реально собраны, но запуск, установка, обновление и
удаление на Windows ещё не проверялись. Цифровой подписи нет;
Windows может показать предупреждение о неизвестном издателе.
Все критерии production-релиза из технического задания ещё не закрыты.
Полный список выполненных проверок и оставшихся работ — в исходниках,
в README.md и docs/validation.md. MSI и Linux-пакеты здесь не собраны.

УДАЛЕНИЕ
Обычное удаление сохраняет историю. Перед обновлением или удалением
завершите ClipVault через Quit в трее.
Для удаления всей истории и настроек отдельно завершите программу и
явно удалите папку %APPDATA%\io.clipvault.desktop.
