# Contributing

Install the documented prerequisites and run README checks. Include actual results; never infer native compatibility from successful compilation. Tests must use temporary, non-sensitive data. Do not attach real history databases or clipboard dumps to bug reports.

Keep migrations sequential and preserve existing history. Preserve pins during automatic cleanup. Review image-file consistency and privacy whenever adding capture formats. Commit lockfiles with dependency changes. Platform behavior needs tests in the actual desktop/compositor.

Outstanding work is in docs/validation.md and README. Public releases require Windows installation testing, cross-platform clipboard tests, signing decisions and explicit owner authorization. Do not enable updater endpoints without signed update artifacts and verified keys.
